# Kid Code Studio

面向 5–12 岁儿童的无代码动画与 2D 游戏创作平台。当前已完成无需账号即可使用的本地 MVP；云端账号、作品分享、AI 助手、完整课程/家长端和录音上传按产品决策暂缓。

## 当前能力

- Scratch Blocks 图形化编程工作区
- 运行、暂停/继续、停止、全屏试玩和键盘/触控方向控制
- 事件、动作、外观、声音、控制、判断、变量和游戏积木的受控执行
- 固定 480×360 逻辑舞台和等比响应式显示
- 12 个内置角色/道具、10 张 4:3 背景和 15 个原创提示音
- 各素材独立的显示比例、锚点和矩形/圆形碰撞轮廓
- 带边界约束、固体阻挡和补间的角色移动
- 运行态角色点击、碰撞进入、金币收集、计分和结果反馈
- PixiJS 舞台气泡、声音、碰撞光环与停止复位
- 运行积木高亮、运行状态和错误反馈
- 可取消的运行时调度，以及领域模型、编译器和运行时单元测试
- 角色独立的 Blockly 工作区快照、IndexedDB 两秒自动保存和异常草稿恢复
- `.kidgame` 完整包导入导出（项目、缩略图和素材），兼容 JSON 项目
- 作品复制、7 天回收站、舞台缩略图和最近编辑时间
- 触控友好的角色与场景管理（新增、复制、重命名、排序、删除与撤销）
- 自定义 PNG/JPG/WebP 角色和背景上传，以及支持触控的简易绘图编辑器；二进制独立于项目 JSON 保存
- 舞台角色拖拽吸附格心和沉浸式全屏试玩；大格舞台使用从 0 开始的 12×9 格坐标，“移动到 X/Y”以列/行为单位（旧像素积木打开时自动换算）
- 三个起步模板、六个单元共 32 关（含可直接进入的固定路线挑战与云岛远征）、三级提示和基于实际运行结果的完成判定
- 独立课程地图、继续学习与关卡作品续开
- 1366 桌面、1024 紧凑桌面和 iPad 横屏的 Playwright 回归用例

## 开发命令

```bash
pnpm install
pnpm dev
pnpm check
pnpm test:e2e:list
pnpm test:e2e
```

本地预览默认地址为 `http://127.0.0.1:4173/`。推荐横屏使用，编辑器的逻辑舞台始终为 480×360。

## 架构约束

- 领域层不依赖 React、Scratch Blocks、PixiJS 或 DOM。
- 运行时不执行任意 JavaScript，只解释经过校验的 AST。
- 编辑态和运行态分离。
- 业务数据只通过稳定资源 ID 引用素材。
- 用户图片二进制存入 IndexedDB，项目 JSON 不内嵌 Base64。
- 内置视觉素材和声音均维护来源/授权状态，详见 `apps/web/public/assets/asset-manifest.json`。
