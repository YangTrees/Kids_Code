程序矩阵中的通用错误是“动作未连接到开始事件”，按每个实际角色工作区生成；修正后恢复连通结构。等价解包含拆分步数、等价转向、整句答案标点、其他合法音效或初始观察等待，取决于本关规则。既有课程专项测试继续检查错误计数、条件、动作和负面答案。这里不把一组错误解宣称为全部可能误解。

完整程序、输入、运行报告、缺失规则见 [assessment.json](../artifacts/full-course/assessment.json)。三视口舞台记录为 `stage-<viewport>.json`，几何记录为 `geometry-<viewport>.json`。所有自动化使用独立测试数据，不访问用户浏览器作品。

## 可重复命令

在项目根目录依次运行，避免 WebGL 浏览器与压缩包单元回归争抢资源：

```powershell
pnpm check
pnpm course:baseline
pnpm exec playwright test e2e/full-course.spec.ts
pnpm exec playwright test e2e/teaching-interactions.spec.ts e2e/data-play.spec.ts e2e/current-course-entry.spec.ts e2e/geometry-acceptance.spec.ts e2e/story-series.spec.ts
pnpm exec playwright test e2e/editor-layout.spec.ts
pnpm exec playwright test e2e/creation-flow.spec.ts e2e/p0-course.spec.ts --project=desktop-1366
pnpm test:course:summary
pnpm test:offline:story
```

三个视口为 1366×768 Chromium、1024×768 Chromium、1194×834 横屏 WebKit。WebKit 触控模拟不等同于真实 iPad。截图位于 `artifacts/full-course/`，生产离线截图位于 `artifacts/story-ip/offline-v4.png`。
