## 5. P1-04 至 P1-07：教学交互与运行表现

### P1-04 教学工具箱

为每关增加受控教学配置，建议字段为 allowedBlockTypes、editableScopes、guideSteps、mentorLines、visualSetId；字段名可按现有类型整理，职责必须保留。工具箱配置不是新的判题规则。

- 新版课程按本关知识点显示必需积木及已学过的合理替代积木；不只从 blockGuide 展示文字反推白名单，要核对运行目标和参考解。
- 阴影数值块、布尔输入和引用对象的依赖一并开放，避免条件块出现却没有可填输入。
- 自由创作保留完整工具箱。全部当前课程使用新版配置；若已保存脚本包含未显示的块，保留并提供明确的工具展开入口。
- 类别按钮、实际块色、创建变量入口、提示示意共享同一配色来源；品牌橙蓝紫不改变积木类别语义。
- 新教学项目默认隐藏与本课无关的素材管理、像素信息和高级设置；复制为自由作品后恢复完整编辑器。

### P1-05 参数选择

数字提供常用值和加减按钮，保留合法范围内直接输入。旋转展示常用角度，移动展示“格”，等待展示“秒”；X/Y 显示列/行与地图坐标，沿用已有从 0 开始的换算，不能悄悄改为 1 起始。

对象选择用实际角色缩略图与名称，场景选择用预览图。创建变量改为站内对话框，处理重名、空白、取消、键盘确认与焦点归还，避免继续依赖 window.prompt。参数编辑的 pointer/touch 事件不得冒泡成为积木拖动；关闭后不遗留拖拽状态。

可操作区域以 44 CSS px 为设计基准。弹层在 1024×768 和 WebKit 触控模拟中不被裁切；不能通过整体放大积木使工作区失去可用面积。

### P1-06 角色引导与奖励

团团承担“我想试试”和预测问题，点点承担一条可执行提示或运行后的观察。两者是预设教学文案的呈现角色，不显示正在调用 AI 或自动理解孩子代码等尚不存在的能力。

首关引导依次观察“放入开始事件 → 连接说话 → 实际运行并得到反馈”。点击“下一步”不能代替真实动作。支持跳过、重看，失败保留积木；任务卡同时只突出一个下一步。

三级提示依次为观察目标、定位相关积木、示例结构；原有必须达到的目标与数量不能在改文案时删掉。积木示意从真实块定义渲染，数值、颜色、帽子/循环形状与编辑器一致，图片中不烘焙积木。

完成奖励只依赖目标完成，不因提示级数、失败次数或耗时扣除。记录“使用过提示”与“完成”两个独立事实；不把未使用提示等同于已独立掌握。旧 stars 记录保留，新奖励显示通过兼容层读取完成状态，不回写旧历史以制造进步数据。

### P1-07 尺度与碰撞

舞台仍为 480×360，默认大格 40，12×9；保留小格和旧作品兼容。网格占位、起点、目标、路线与结算继续由代码决定。

新角色按可见身体轮廓校准，而非整张 PNG 包围盒；初始目标为身体高度约 0.8–0.95 个大格，再按实际小屏辨认结果登记最终值。头像另提供 44–64 CSS px 清晰展示，不通过放大舞台碰撞体解决头像辨认问题。

逻辑位置始终是格心，新造型的可见主体中心也对齐格心。脚底中点、悬浮投影中心作为美术测量参考；不能直接将脚底锚到格心而使身体跨到上一格。光晕、天线、背包外缘及装饰不能自动扩大碰撞体。移动的动画落到格心；转向、气泡、成功表情不能改变逻辑位置。此处由首批真实舞台样片验证后修订，旧造型几何保持原样。

必须分别验证：接触宝箱边缘、进入路线终点格、进入可收集物、离开再进入、一步跨过目标、隐藏目标、旋转/缩放、切场景与停止重跑。视觉替换前后用相同输入比较关键结果；若结果不同，先查几何配置，不把通关阈值改宽来掩盖。

| 1 / speak         | 开始事件与说话 | 团团提出目标，点点示意真实事件帽子与说话积木 | 单击教学下一步不算完成；实际运行才推进；跳过后可重看 |
| 2 / move          | 移动与格坐标   | 清晰格心、脚底落点、前后位置对照             | 拖动吸附、积木移动和目标判断使用同一套坐标           |
| 3 / sequence      | 执行顺序       | 用角色观察提示先后关系；运行高亮对应实际积木 | 相同积木不同顺序的结果可解释；不强制唯一搭法         |
| 6 / repeat        | 重复           | 将次数与循环体分开示意；展示一次循环的范围   | 编辑次数不触发拖拽；单步和连续运行结果一致           |
| 7 / collision     | 碰撞事件       | 点点说明“碰到时”而非笼统“站在附近”           | 首次进入触发、持续接触不重复、离开再进入符合现有语义 |
| 26 / path_turn    | 路线转弯       | 水彩环境置于外围，路径与方向箭头程序绘制     | 转向不平移；格心、朝向与路线拐点一致                 |
| 28 / path_repeat  | 路线中的重复   | 用路径段高亮解释循环，而非只给最终答案       | 跨格检查不能穿越障碍；已有合法等价解继续通过         |
| 37 / data_compare | 数据比较       | 数据工作台用准确的图表和角色提问             | 柱高、数量、标签与判定同源；颜色不是唯一识别线索     |

每关至少留存正确解、典型错误、修正后成功三条完整记录，共至少 24 条。另执行停止重跑、重载续开、提示展开、触控参数编辑；不将三条样例当作全部测试覆盖。
