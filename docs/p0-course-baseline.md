# P0 课程可信基线实施记录

本轮对应全面审核方案 A01–A05。当前任务内容版本为 3，作品会携带课程版本、角色与数据变量绑定及起始布局。原作品和完成记录继续保留。

## 已实现的行为

- 第 57 关统一为先归零、循环五次、每次加分后判断、在第 3/4/5 次提醒。第 62 关统一消息接收、四组双音效、等待和最终成功要求。
- 运行目标前置到舞台上方的首屏区域，任务卡显示当前下一步，全部检查项默认折叠；长面板提供可见滚动入口。数据课精简辅助舞台，优先展示分类和图表。
- 记录提示和故事台词允许自选；分类答案按明确的同义标签匹配，否定词不会因包含肯定词而误通关。
- 任务使用作品携带的角色和变量绑定。修改任务起点、角色造型、道路或格距时，会解释不一致并提供恢复布局或复制到自由创作。
- 恢复布局保留现有积木，并通过编辑历史支持撤销。
- 首页导航、编辑器错误返回、浏览器测试与图片路径统一支持 /KidsCode/；紧凑屏幕保留学习与家长区两个必要入口。
- CI 安装 Chromium 和 WebKit；Windows 预览监听工作区源码，避免加载旧项目协议。

## 旧作品与版本策略

版本 3 使用本轮目标、提示和判定。版本 2 保存难度调整后、本轮 P0 前的规则，并仅修正第 57 关展示文案，不改变其五次观察判定。

只有 taskId、没有内容版本的历史作品无法精确识别其创建时的课程修订，使用版本 1 的兼容规则：不强制新加入的组合循环、五次提醒或数据分类流水线。保留原位置、道路、积木与更新时间；首次打开时添加版本元数据并自动保存，界面显示旧版任务。

当前提供“新建新版 · 保留原作品”，生成独立项目，不自动改写旧地图、脚本或已完成进度。旧版的提醒助手仍可用三次加分后判断通关；新版要求五次逐轮判断。未知内容版本不参与通关评价，当前作品仍可复制到自由创作。

版本随 .kidgame 项目包保存，不依赖当前浏览器的任务 key。运行记录带 taskId 与 taskVersion，不能借用其他关卡或版本的运行结果通关。

冻结版本文件位于 apps/web/src/features/tasks/versions。后续改变课程目标或判定时必须发布新内容版本，不直接重写已发布版本。旧版保留兼容要求，不用于推断孩子已独立掌握新版课程。
